# Wedding Hall Management System 💍

## 📌 Project Overview

This project is a Wedding Hall Management System developed using C#.
It is designed to manage bookings, customer details, and staff operations efficiently.

## 🎯 Objectives

* Manage wedding hall reservations
* Store customer information
* Manage staff details
* Provide an easy-to-use interface
